 iPhone Sales Analytics Dashboard (Power BI Project)


 Project Overview
This project is an end-to-end data analytics solution built to analyze iPhone sales performance using Power BI.

The workflow covers data cleaning in Excel, data modeling, and the creation of an interactive Power BI dashboard that delivers actionable business insights across sales performance, customer behavior, and product trends.


 Data Preparation & Cleaning (Excel)
Before visualization, the dataset was carefully prepared using Excel:

- Removed duplicate and inconsistent records
- Handled missing and null values
- Standardized product names, categories, and formats
- Ensured data consistency for Power BI modeling


 Dashboard Highlights (Power BI)
The dashboard is fully interactive and includes dynamic filtering and slicing capabilities:

-  Total Sales, Orders, and Quantity KPIs
-  Sales performance by iPhone model
-  Regional sales distribution (Country-level insights)
-  Payment method behavior analysis
-  Storage capacity preferences (GB breakdown)
-  Monthly sales trend analysis
-  Customer color preference distribution
-  Average sales per transaction



 Key Business Insights
- iPhone Pro models dominate total revenue contribution
- Credit card payments are the most widely used method
- 256GB storage variant is the most preferred among customers
- The USA and UK are top-performing markets
